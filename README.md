I build firmware for connected devices, from **register-level drivers on bare-metal microcontrollers** to the **wireless link and the data behind it**. I like understanding a system down to the datasheet: clocks, interrupts, buffers and protocols. Then I make it reliable enough to ship.

### 🔭 Currently

**IoT Research Engineer Intern at [IMT Atlantique](https://www.imt-atlantique.fr/en)** (Rennes, France). I'm working on context-aware **indoor localization**: fusing smartwatch data (Wi-Fi RSSI, barometric pressure, BLE) with **Wi-Fi fingerprinting and Hidden Markov Models** to track a person's zone inside a building.

### 🛠️ What I work on

- **Bare-metal firmware & drivers**: STM32 / ARM Cortex-M4, direct register configuration through CMSIS, interrupt-driven UART, timers, DMA
- **Connectivity**: Wi-Fi (ESP8266 / ESP32), LoRa / LoRaWAN, BLE, MQTT, TCP/IP
- **Real-time & embedded Linux**: FreeRTOS tasks and synchronization, Linux tooling
- **Hardware**: schematic & PCB design in Altium Designer, bring-up with oscilloscope and logic analyzer
- **Data for IoT**: sensor fusion and probabilistic models in Python / MATLAB
