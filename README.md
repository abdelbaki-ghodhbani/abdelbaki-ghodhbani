- **Firmware**: bare-metal firmware development and device drivers on STM32 (ARM Cortex-M4), ESP32, ESP8266 and Arduino
- **Peripherals**: GPIO, ADC, Timers, PWM, Interrupts, DMA, UART, I2C, SPI, CAN
- **Connectivity**: Wi-Fi, BLE, LoRaWAN, MQTT, TCP/IP
- **Operating systems**: FreeRTOS, Linux
- **Hardware & debugging**: PCB design in Altium Designer; JTAG, SWD, GDB, oscilloscope, logic analyzer
